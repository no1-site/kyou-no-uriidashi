# ValueCommerceによる家電量販店比較の拡張方針

## 採用方針

家電量販店の自社サイトを直接スクレイピングせず、広告主が許可した商品データをValueCommerce商品APIから取得する。
商品APIは広告主の商品検索、異なる広告主の同一商品の価格比較を用途として案内されている。

本番では次を満たす場合だけValueCommerce取得を有効にする。

1. 今日の売り出しAI便がValueCommerceのサイト審査を通過している。
2. 対象広告主と提携済みで、「対応機能別 > Webサービス」に商品API対応が表示されている。
3. 商品APIトークンをWindowsローカルに暗号化保存している。
4. 対象広告主のECコードを明示的な許可リストとして保存している。

トークンまたはECコードがない場合、既存の楽天・Yahoo更新だけを行い、公開処理には影響しない。

## 照合ルール

- 正式台帳のJANとAPIのjanCodeが完全一致する商品だけ採用する。
- 中古・訳あり、在庫なしは除外する。
- 商品名・説明にセット、容量違い、関連部品等の既存除外条件があれば除外する。
- 同じ広告主の複数結果は最安の1件だけ残す。
- ValueCommerceが返す送料項目が「なし」の場合だけ送料込み扱い、「あり」は送料別、それ以外は要確認。
- ポイントは価格から差し引かない。
- HTTPSのアフィリエイトリンクが確認できない結果は採用しない。

## 対象候補

公開情報ではヤマダ電機がValueCommerceのMyLinkBox対応広告主として案内されている。
Joshinは自社規約上アフィリエイト流入を扱っているが、商品API（Webサービス）の提供有無は管理画面で確認する。
ビックカメラもアフィリエイト流入を扱っているが、商品API対応は管理画面で確認する。自社サイトの直接スクレイピングは行わない。
ヨドバシ.comは現時点で公式の商品API・アフィリエイト商品データ提供を確認できていないため、自動取得対象にしない。

## Windowsセットアップ

ValueCommerce側の準備が完了したら以下を実行する。

```powershell
.\scripts\setup-valuecommerce.ps1
```

商品APIトークンはクリップボードから読み取り、Windowsユーザーに紐づく暗号化形式で保存する。
ECコードはカンマ区切りで明示し、許可リスト外の広告主は比較表へ追加しない。
