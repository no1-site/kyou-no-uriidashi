# 送料金額の取得実験（2026-09-18）

対象は掲載中の食品・ペットフードを扱うショップ。注文・カート操作・ログインは行わず、公開ページを調査した。

## 確認できたこと

- [ウエノ電器の配送案内](https://www.rakuten.co.jp/u-denki/info2.html)：ページ閲覧では通常配送660円の記載を確認。一方で大型便・商品別の例外や離島についても記載があり、各商品への適用確認が必要。Node.jsからの取得は今回タイムアウトした。
- [サンドラッグの配送案内](https://www.rakuten.co.jp/sundrug/info2.html)：通常便の地域別表に長崎県600円・沖縄県1,210円の記載を確認。購入額による無料条件、離島の追加料金、クール便など複数の配送区分もある。Node.jsからHTTP 200で取得でき、EUC-JPの本文を読み取れた。
- purpleshadowの配送案内と、食品2店の商品ページは閲覧ツールで取得できず、個々の商品に適用される配送方法の確認には至らなかった。
- サンドラッグも後続の同一URL取得はタイムアウトした。最初の抽出では一般料金候補300円・0円を取得できたが、地域別表はHTMLの改行・タグ構造に合わせた処理が必要だった。処理を修正してテストしたものの、修正後の実ページでの再検証はタイムアウトにより未完了。継続取得の安定性は未確認。

## 判定

店の送料表を取得することは一部可能。ただし、送料表の数字だけで商品の支払総額を確定できない。今回確認した128円の商品に通常送料600円が適用されるなら合計728円になるが、これは適用条件を仮定した計算であり、確認済み総額ではない。サイトにはこの仮定の金額を掲載しない。

`scripts/probe-shipping.mjs` は一般料金・地域別料金の候補を抽出するだけで、`usable_for_totals` は常にfalse。配送方法・商品個別条件・配送先（離島を含む）・購入数量と無料条件の対応が未確認であることを出力する。日次更新には接続していない。

現時点の公開サイトは送料込み表示の店が2店以上あればその範囲で比較し、送料別・未確認の店は参考欄に残す。送料金額の自動取得が全店で安定稼働したとは扱わない。
